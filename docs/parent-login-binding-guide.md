# 家長登入與孩子綁定使用說明

日期：2026-10-18。

## 使用流程

1. 依登入頁提供的方式驗證身分。驗證渠道待確認；本說明不限定 SMS 或 Email。
2. 首次使用時，輸入醫護提供的一次性邀請碼，綁定指定孩子。
3. 完成綁定後，之後只需登入即可取得仍有效的孩子關係；新增孩子時使用另一份邀請。
4. 選擇孩子，查看指定問卷、暫存與提交，再追蹤完成狀態。

登入證明帳號身分；綁定決定可存取的個案。不能用姓名、生日或個案編號直接取得孩子權限。

## 常見問題

| 情況 | 建議操作 |
| --- | --- |
| 邀請碼無效 | 確認輸入與邀請種類，向醫護確認；個案綁定邀請與教師授權不是同一種碼。 |
| 邀請碼已使用 | 先查看自己的孩子列表；不可再次兌換同一份邀請。 |
| 已撤銷／被解除綁定 | 停止存取，聯絡醫護確認是否重新核准及發出新邀請。 |
| 更換手機或聯絡方式 | 由醫護協助確認身分與更新方式，再重新驗證；不自行建立另一個帳號承接舊資料。 |
| 沒有問卷 | 核對孩子及指派情況，向醫護確認，不能自行選版本或輪次取代指派。 |
| 斷線／版本衝突 | 未顯示成功前不認定保存完成；依畫面確認結果及重新載入，不盲目覆寫。 |
| 提交後需補充 | 家長、教師不可修改原始答案，聯絡醫療團隊處理。 |

家長只查看教師是否完成問卷，不取得教師答案、分數、補充觀察或草稿。撤銷權限不刪除原有答案，也不自動把原作者資料交給另一位照顧者。

## 本輪交付與界線

- `wwwroot/parent-help.html` 是不含個資的公開使用說明。
- `wwwroot/js/parent-help.js` 提供家長展示及 account 模式共用說明；內容只描述操作，不負責身分驗證。
- 獨立同意書介面位於 [同意書設計稿](prototypes/parent-consent-review.html)，沿用現有字體、配色與院徽，不加入正式網站的同意流程。
- 設計稿包含閱讀、勾選、確認、返回及取消；不呼叫 API、不使用 localStorage、不保存同意、不建立 Grant。
- 正式本文、文件版本、保存期間、撤回影響與 Consent Entity／Migration 仍待院方及團隊確認。
- 正式登入 provider、首次帳號建立、跨帳號轉移、問卷作者隔離及並發處理仍未因此完成。

- 公開使用說明、共用 JS／CSS 的 HTTP 回應皆為 200。
- 工作台展示模式的「使用協助」已實際切換並顯示九項問答，無瀏覽器 JavaScript 錯誤。
- 公開說明的 FAQ 可用 Enter 展開。
- 同意介面於 1440×900 檢查：文件寬 1440，確認框邊界在可視範圍內，預設聚焦「返回閱讀」。
- 未勾選時不能開啟確認框；勾選、Escape 返回、完成介面檢視及取消均已操作確認，結束後重設勾選並提示沒有正式紀錄。
- 30 項既有前端測試、語法檢查及 `git diff --check` 通過；本輪說明與設計稿為低風險靜態介面，不另新增對照文字內容的測試。
- 正式 account 模式共用相同說明元件，但本輪未重新執行正式帳號／MySQL 驗收。
- 本輪成果依使用者指示隨功能分支提交／推送；沒有新增正式同意 API、模型或 Migration。
