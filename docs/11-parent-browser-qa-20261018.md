# 家長前端隔離驗收結果

日期：2026-10-18。

## 環境

使用既有 `CaseGuardianHarness --serve-browser-fixture` 的一次性 SQLite 測試環境，僅綁定 `127.0.0.1:5182`。測試身分、情境切換與虛構資料只存在測試執行檔，不註冊到正式網站，不連 MySQL、不寄送簡訊或 Email。

新增的 `/fixture-scenario/{scenario}` 及 `/fixture-binding-count` 僅在 fixture 旗標下註冊，用來穩定模擬 HTTP 401／403／503 及慢速綁定，不是正式 API。

## 實際結果

| 案例 | 結果 |
| --- | --- |
| 未登入直接進 account 工作台 | 顯示「請先登入家長帳號」，孩子與綁定操作停用。 |
| 載入測試孩子 | 正確顯示孩子、本人聯絡資料及任務統計。 |
| 無任務 | 顯示 0 與沒有待填問卷，不加入展示任務。 |
| HTML 403 | 顯示權限不足，清除孩子及聯絡資料，停用孩子選擇與綁定。 |
| HTML 503 | 顯示無法確認結果及重新載入入口，不顯示舊資料。 |
| 恢復服務後重新載入 | 恢復目前有效的孩子及資料。 |
| 慢速綁定連按兩次 | 處理中按鈕停用，測試伺服器計數僅 1 次；無效邀請後顯示錯誤並可再操作。 |
| 提交綁定時回 401 | 關閉對話框，清除孩子資料，顯示登入逾期及返回登入入口。 |
| 1440×900 CSS px | 文件寬 1440，沒有橫向溢出；綁定對話框在可視範圍內。 |

正常資料、拒絕存取與失效後的頁面均透過瀏覽器可見狀態確認。逾期畫面證據存於本機暫存 `earlycare-parent-expiry-20261018.png`，不將暫存路徑視為其他組員可取得的附件。
