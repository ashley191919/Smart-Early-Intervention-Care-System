# 試做版登入頁

依 Figma「試做版」的家長登入（第二版）、教師登入（第二版）與醫護登入畫面實作。共用卡片寬 480px、綠色頂線、三種身分分頁與淺色背景，並支援手機排版。

以原有 ASP.NET Core 專案的 `wwwroot` 提供 HTML/CSS/JavaScript，無須安裝另一個前端框架。原本 Swagger、教師測試表單及授權 API 保留。

## 開啟

在 Visual Studio 啟動專案後，使用與 Swagger 相同的主機與連接埠，將 `/swagger` 換成 `/`：例如 `https://localhost:7127/`。保留既有 launchSettings，啟動時仍會先開 Swagger。

可直接開啟 `/?role=medical` 或 `/?role=teacher` 查看指定入口。

## 已完成

- 三種入口的版面、欄位、按鈕與分頁切換。
- 必填欄位、家長手機格式檢查、密碼遮蔽。
- 鍵盤方向鍵切換分頁、可關閉的 FAQ 與說明對話框。
- 教師提示依最新規格改為「不限時，提交成功或撤銷後失效」。

## 前端分工與整合方式（2026-10-04 確認）

- A：醫療人員登入與登入驗證相關畫面。
- B：家長登入與家長端相關畫面。
- C（洪靜吟）：教師授權碼、QR Code 與授權驗證相關畫面。

三人先在各自分支完成，再共同整合。本分支目前保留三種入口的試做畫面供比對；不代表 C 接手 A、B 的前端工作。醫療入口需與 A 已完成的登入及驗證中畫面比對，再決定整合版本。這是前端分工，後端身分驗證與角色／權限責任仍依原分工。
