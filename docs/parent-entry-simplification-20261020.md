# 家長端導覽與進入同意視窗調整

日期：2026-10-20。依使用者本輪明確要求調整前端，不延伸刪除共用後端。

- 家長工作台與家長問卷側欄統一四項：我的首頁、我的問卷、我的孩子、使用協助。
- 移除兩個舊分頁與首頁教師進度卡；舊 page=teacher／consent 回到首頁，正式家長前端不再呼叫 teacher-completion。
- 家長側欄中心名稱改為「兒童發展評估暨療育中心」。
- 進入家長工作台後顯示資料使用與教師填答選項。資料使用必選、教師選填，兩者預設不勾；不同意可返回登入。未登入或 account 載入失敗不顯示同意視窗。
- 同分頁跳轉透過 sessionStorage 保存本次 UI 選項，重新登入／登出清除，避免每個分頁都重複跳窗。

## 實作邊界

這是新的前端流程與本文草稿，尚非核定的正式同意機制。現有後端沒有正式 Consent 保存 API，未新增 Entity、Migration、TeacherGrant 或撤銷規則。

`earlycare.parent.entry-choice.ui.v1` 只供前端導覽連續性，不能當成正式同意紀錄、Guardian 權限或教師授權。勾選教師不會產生授權碼、寄送邀請或呼叫開發 Grant API。正式整合仍須確認本文／版本、個案與任務範圍、可信操作者、後端保存及權限檢查。

保留 teacher-completion 及共用 Grant 後端，不因本輪移除家長頁面而擅自刪除共用 API。原開發盤點文件保持歷史基準，不改寫為新功能已正式完成。
