# 家長前端提交後導覽與完成數量檢查

日期：2026-10-19。檢查使用者提供的兩張 23:14 截圖。

## 原因

圖二是 `parent-workspace.html`，圖一是 `parent-questionnaire.html?mode=demo&task=...`。不是同一頁重新排版。

舊版共用填答程式只把 URL 的單一 task 載入 forms，因此任一份提交後就顯示 1/1、全部完成及 0 份待填；這個分母不代表家長儀表板的本輪全部任務。成功頁「查看本次完成狀態／返回任務首頁」只切到填答頁內的 home 區塊，沒有回到原家長儀表板。

家長填答頁另有沿用教師端的校園觀察、教師授權不限時及家長撤銷後失效等文字；把家長登入、個案綁定與教師 Grant 混為一談。

這條 mode=demo 流程使用 SharedDemo／localStorage；不代表 Email／Guardian 正式登入或答案已寫入 MySQL。這次不更動正式後端、資料庫、授權或 Migration，也不清除使用者既有瀏覽器資料。

## 已修正

- 共用前端新增 parentTaskScope：依被點選任務的 caseId＋round，載入同孩子、同輪次的所有家長問卷；排除其他孩子、其他輪次與教師任務。網址指定哪份就開哪份，不因載入多份而改開第一份。
- 成功頁依整個範圍計算完成度；未全部完成保留下一份問卷，任何時候均提供「返回家長儀表板」。填答頁的返回按鈕及側欄家長儀表板也回到原頁。
- 家長頁改為家中觀察、醫療團隊及本輪問卷進度；列表標題改「本輪指定問卷」，避免已提交項目出現在「待填問卷」標題下。
- 儀表板的「提交紀錄」開啟唯讀紀錄，不重新進入填答工作台。
- 歷史還原時重新同步瀏覽器任務狀態；正式家長 token 存在時不進入舊示範填答，轉回 account 儀表板。缺少有效任務時不自動開啟預設的兩份問卷。
- 已更新相關 script 的資源版本；未修改教師正式提交 API 或角色權限。
