# 家長儀表板前端（2026-10-10）

11 號製作家長入口、首頁與操作預覽；16 號的家長／教師共用表單模組負責正式問卷填答、Draft、Submit、Response。Migration 由 16 號統整。本次不變更後端或資料庫。

## 文件依據

- 專題規劃：個案基本資料、SNAP-IV、克氏行為量表、家長滿意度等表單電子化。
- 共用契約 `shared-contract-v1.md`：手機 OTP 與首次邀請碼綁定分開；問卷由醫護指派；家長只查看教師是否完成；授權不限時，全部指定問卷提交或撤銷後失效。
- 較早專題文件的教師授權期限描述，依後續已確認的不限時規格處理。

## 畫面及操作

- 我的首頁：目前孩子、問卷待辦、草稿與已提交數量、教師授權入口及教師完成狀態。
- 我的問卷：全部／待填／草稿／已提交篩選。按鈕目前顯示與 16 號串接的說明，不假造正式題目或收據。
- 我的孩子：虛構孩子基本資料、主要聯絡人預覽、首次邀請碼綁定與多孩子切換。
- 教師授權與進度：示範碼建立、撤銷、完成情境。沒有教師答案、分數、判讀或觀察資料。
- 同意與資料使用：資料用途及可見範圍，未宣稱正式知情同意已完成。
- 使用協助：綁定、填表、教師授權與常見問題。

## 預覽驗收

網址：`http://localhost:5177/parent-workspace.html`，也可完成登入頁示範後進入。

1. 我的問卷切換各狀態篩選。
2. 教師授權：建立示範碼、確認撤銷、逐份示範提交。
3. 孩子選單切換「尚未綁定情境」，輸入邀請碼 → 核對孩子資料 → 勾選確認 → 完成。`DEMO-CHILD-002` 可預覽第二位虛構孩子；核對或取消前不加入孩子清單。已完成後重用同碼應提示已使用。
   - `DEMO-EXPIRED`：過期；`DEMO-USED`：已使用；`DEMO-REVOKED`：已撤銷；`DEMO-PHONE`：手機不符；其他碼：無效。
   - 核對頁「資料不符／重新輸入」返回第一步；關閉或 Esc 取消流程。
4. 關閉／Esc 退出對話框；側邊切換後主內容捲動歸零。
5. 重新整理即恢復原始 fixture，不保存帳號、手機、授權或答案。

## 補齊分享與狀態畫面（2026-10-10）

- 有效示範教師授權可開啟分享對話框、複製示範碼、複製本機教師預覽網址。
- QR Code 為本機 `http://localhost:5177/teacher-workspace.html?preview=1` 的靜態 SVG；不帶授權憑證，只開啟教師畫面預覽。其他裝置的 localhost 不代表這台電腦，正式部署須由後端提供可分享的授權網址並生成對應 QR Code。
- 授權撤銷或指定問卷全部完成後，不提供分享入口；已完成時不重發同輪授權。
- 上方「情境預覽」可切換載入中、載入失敗、沒有指定問卷、登入逾期；前端不實際更動會話或呼叫資料 API。
- 原生剪貼簿失敗時提供手動複製提示；未發送任何外部訊息。
- 已驗證 1440 × 900 首頁、狀態畫面與分享對話框，390 × 844 分享對話框無橫向溢出。

剩餘正式整合：16 號的家長問卷填答頁、Draft／Submit／Response；正式 OTP、綁定、知情同意、教師授權與完成狀態 API。這些前端試做不等於正式功能已完成。

## 任務範圍與逐份完成修正（2026-10-11）

- DEMO-001 為第 2 輪複評，首頁計數只包含本輪三份家長待辦。我的問卷分本輪與過往提交紀錄；保留輪次、示範版本及過往提交的臺灣時間。過往滿意度標為服務後調查，不計入本輪評估。
- 教師進度從本輪 teacherTasks 逐份產生，不共用完成布林值。家長只看是否完成，沒有教師草稿、答案或分數。
- 授權保存固定 taskIds，只包含尚未完成的本輪教師任務。完成一份仍有效，全部指定任務完成才結束，已完成不能反向改成未完成。
- 撤銷保留完成狀態；重建只包含剩餘任務。第二位示範孩子 DEMO-002 只有基本資料任務，沒有教師指派，無法建立授權。
- 驗收：建立 → 第一份示範提交 → 仍有效 → 第二份提交 → 已完成。另重新整理測試第一份完成 → 撤銷 → 重建只包含另一份 → 完成。綁定 DEMO-002 後教師頁顯示尚未指派。
- 仍為本頁記憶體虛構資料，示範提交不會同步教師頁；正式連動需接共用任務、提交與授權 API。未更動後端或 migration。
